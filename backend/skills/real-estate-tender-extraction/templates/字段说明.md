# 地产招标文件核心信息提取模板字段说明

## Sheet 1：招标关键信息汇总

| 字段 | 填写口径 |
|---|---|
| 序号 | 从 1 开始连续编号 |
| 业务类别 | 综合通用、商务标、技术标、资信标 |
| 关联类别 | 与该事项相关的其他类别，可为空 |
| 信息主题 | 简短概括，如“投标截止时间”“项目经理资格”“报价方式” |
| 关键信息 | 不改变原意的结构化提炼 |
| 原文摘录 | 从招标文件逐字复制的原文证据 |
| 来源文件 | 招标文件、答疑、补遗、合同条款、技术标准、清单说明等 |
| 页码 | 文件页码或 PDF 页码 |
| 章节/条款号 | 章节名称、条款号、表格编号或附件名称 |
| 业务解读 | 面向投标编制的解释，不得替代原文 |
| 对投标文件的影响 | 说明影响资信、技术、商务、封装、响应或报价的动作 |
| 风险等级 | 高、中、低 |
| 可信度 | 高、中、低；缺少来源位置时不得为高 |
| 是否需人工复核 | 是、否 |
| 复核意见 | 人工复核后的结论 |
| 备注 | 其他说明 |

## Sheet 2：综合通用事项

| 字段 | 填写口径 |
|---|---|
| 事项类型 | 项目概况、时间节点、保证金、递交、封装盖章、暗标、废标、合同风险、格式附注、其他 |
| 责任部门 | 投标负责人、商务、技术、资信、法务、项目经理部等 |
| 对应投标动作 | 需要执行的编制、上传、盖章、复核、澄清或响应动作 |

## Sheet 3：商务标

| 字段 | 填写口径 |
|---|---|
| 商务事项类型 | 控制价、报价方式、清单规则、不可竞争费、暂列暂估、调价、付款、结算、担保、商务评分、合同风险、其他 |
| 报价/合同/计价要求 | 结构化记录商务要求 |
| 涉及金额/费率/公式 | 金额、比例、费率、计算公式或计价口径 |
| 对报价文件的影响 | 报价组价、清单填报、成本测算、合同风险响应等影响 |

## Sheet 4：技术标

| 字段 | 填写口径 |
|---|---|
| 技术事项类型 | 技术评分、施工组织、进度、质量、安全、文明施工、环保、BIM、重难点、资源配置、暗标格式、技术标准、其他 |
| 技术编写要求 | 技术方案必须写入或响应的内容 |
| 评分分值/响应要求 | 分值、评分标准、必须响应或扣分点 |
| 对技术方案的影响 | 章节设置、重点内容、格式控制、图表要求等 |
| 暗标相关 | 是、否；如是，记录具体暗标限制 |

## Sheet 5：资信标

| 字段 | 填写口径 |
|---|---|
| 资信事项类型 | 企业资质、人员资格、业绩、信誉、财务、社保、纳税、认证、资格审查、资信评分、其他 |
| 资格/证明/评分要求 | 结构化记录资格或评分要求 |
| 证明材料要求 | 证书、合同、中标通知、竣工验收、社保、审计报告、截图等 |
| 对资信文件的影响 | 资料准备、证件核验、评分争取、资格风险等 |

## Sheet 6：风险与复核清单

| 字段 | 填写口径 |
|---|---|
| 风险类型 | 废标、资格、报价、合同、时间、格式、暗标、冲突、缺失、其他 |
| 影响范围 | 影响综合响应、商务报价、技术方案、资信资格、封装递交等 |
| 建议复核动作 | 人工核对、向招标人澄清、法务复核、商务测算、技术确认等 |
| 优先级 | 高、中、低 |
| 责任人 | 业务实际负责人，可为空 |
| 复核结论 | 人工复核后填写 |

## 通用枚举

- 业务类别：综合通用、商务标、技术标、资信标
- 风险等级：高、中、低
- 可信度：高、中、低
- 是否需人工复核：是、否
- 风险类型：废标、资格、报价、合同、时间、格式、暗标、冲突、缺失、其他
