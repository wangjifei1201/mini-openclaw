# 地产招标文件核心信息提取

## 概述

用于从地产行业招标文件中提取所有会影响投标文件编写、响应合规、报价、技术方案、资信证明、递交封装或废标风险的要求。原文是证据，必须保留原貌；业务理解只能写入解读类字段。

## 适用场景

当用户需要解读或提取以下地产招标材料时使用：

- 招标公告、投标人须知、投标人须知前附表、评标办法
- 合同条款、技术标准、工程量清单、报价说明
- 投标文件格式、附件、附表、文字附注、答疑、补遗、澄清
- 商务标、技术标、资信标、资格审查、响应性评审、废标风险

不用于与招投标、投标文件编制无关的一般文档摘要。

## 不可违反的规则

1. **原文摘录就是证据。** `原文摘录` 必须逐字复制，不得改写、润色、翻译、合并创造或补全缺失内容。
2. **原文和解读必须分离。** 业务理解只能写入 `业务解读`、`对投标文件的影响` 或各分类影响字段。
3. **没有来源位置，不得高可信。** 如果缺少页码、章节、条款号或来源定位，`可信度` 不能标为 `高`。
4. **前三章是重点，不是全部。** 招标公告、投标人须知、评标办法是主抽取区；后续合同、技术、报价、格式、附件、答疑、补遗可能补充或覆盖关键要求。
5. **冲突必须显性保留。** 不同来源冲突时，保留双方原文和来源，并写入 `风险与复核清单`。
6. **高风险事项默认人工复核。** 废标、资格、保证金、时间节点、签字盖章、封装、暗标、报价、合同风险、星号条款、必须响应条款，`是否需人工复核` 默认填 `是`。
7. **默认必须生成 Excel 文件。** 完成提取后，必须主动生成 `.xlsx` 文件；除非用户明确说“只要 Markdown”“只看预览”“不要生成文件”。

## 抽取流程

1. **识别文件结构**
   - 先定位目录、来源文件、章节、页码、附件、投标文件格式、合同条款、技术标准、工程量清单说明、答疑、补遗、澄清。
   - 标记招标公告、投标人须知/前附表、评标办法为主抽取区。

2. **深读前三章**
   - 招标公告：项目概况、招标范围、资格要求、时间节点、保证金、递交方式。
   - 投标人须知/前附表：截止时间、开标、有效期、保证金、签字盖章、封装、上传、响应、废标、格式。
   - 评标办法：资格评审、响应性评审、商务/技术/资信评分、否决条件。

3. **补充扫描后续章节**
   - 合同条款：付款、结算、审计、调价、违约、索赔、保修、风险转移。
   - 技术标准：方案编写、材料设备、验收、质量、安全、环保、BIM/数字化要求。
   - 清单/报价说明：计价依据、不可竞争费、暂列金额、暂估价、税金、缺漏项、公式。
   - 投标文件格式：签字、盖章、附件、证明材料、表格下方附注、禁止修改格式。
   - 答疑/补遗/澄清：变更、覆盖、修正、冲突。

4. **分类入表**
   - 主类别只能是：`综合通用`、`商务标`、`技术标`、`资信标`。
   - 若同时影响多个类别，其他类别写入 `关联类别`。

5. **形成风险与复核清单**
   - 汇总废标风险、原文冲突、缺页缺附件、不明确要求、重大报价/响应影响、需向招标人澄清的问题。

## 业务分类

| 类别 | 必须提取的信息 |
|---|---|
| 综合通用 | 项目名称、标段、地点、招标人/代理、招标范围、时间节点、开标、投标有效期、保证金、递交方式、签字盖章、封装、明标/暗标、必须响应、废标条款、答疑补遗优先级、跨类别合同风险、投标格式附注 |
| 资信标 | 投标人资格、资质证照、项目负责人/技术负责人、联合体、分包限制、信用、黑名单、诉讼处罚失信、财务、纳税社保、银行资信、类似业绩、人员证书、资信评分、资格审查 |
| 技术标 | 技术评分、施工组织设计、实施方案、进度、资源、劳动力、机械、质量、安全、文明施工、绿色施工、环保、BIM、智慧工地、重难点、平面布置、交通组织、暗标格式、技术标准、材料设备、验收 |
| 商务标 | 最高投标限价、控制价、暂列金额、暂估价、甲供材、报价方式、清单规则、不可竞争费、税金、措施费、缺漏项、调价、付款、结算、审计、质保金、履约保证、农民工工资保证金、保险、商务评分公式、异常低价、明显不利合同条款 |

## 高风险触发词

遇到以下内容必须重点识别：`*`、`★`、`加粗`、`下划线`、`特别提示`、`必须`、`不得`、`应当`、`须`、`否则`、`否决`、`废标`、`不予受理`、`无效`、`实质性响应`、`暗标`、`密封`、`签字`、`盖章`、`保证金`、`保函`、`投标有效期`、`最高投标限价`、`不可竞争`、`暂列`、`暂估`、`异常低价`。

## Excel 输出要求

默认交付物是 `.xlsx` 文件，不只是 Markdown 表格预览。

执行要求：

1. 提取完成后，必须主动创建 Excel 工作簿文件。
2. 优先复制或复用 `templates/地产招标文件核心信息提取模板.xlsx` 的 sheet 和表头。
3. 将提取结果写入对应 sheet；不能只在对话中展示表格后结束。
4. 如果当前环境无法写入 Excel 文件，必须明确说明原因，并输出可直接粘贴到 Excel 的多 sheet 表格内容。
5. 只有当用户明确说“只要 Markdown”“只看预览”“不要生成文件”时，才可以不生成 `.xlsx`。
6. 最终回复必须给出生成的 Excel 文件路径。

输出 Excel 时必须包含以下 sheet：

1. `招标关键信息汇总`
2. `综合通用事项`
3. `商务标`
4. `技术标`
5. `资信标`
6. `风险与复核清单`
7. `字段字典`

优先使用 `templates/地产招标文件核心信息提取模板.xlsx`。如果从零生成，使用以下字段。

### 招标关键信息汇总

### 综合通用事项

### 商务标

`序号`, `商务事项类型`, `信息主题`, `报价/合同/计价要求`, `原文摘录`, `来源位置`, `涉及金额/费率/公式`, `对报价文件的影响`, `风险等级`, `是否需人工复核`, `备注`

### 技术标

`序号`, `技术事项类型`, `信息主题`, `技术编写要求`, `原文摘录`, `来源位置`, `评分分值/响应要求`, `对技术方案的影响`, `暗标相关`, `风险等级`, `是否需人工复核`, `备注`

### 资信标

## 字段枚举

- `业务类别`：`综合通用`、`商务标`、`技术标`、`资信标`
- `风险等级`：`高`、`中`、`低`
- `可信度`：`高`、`中`、`低`
- `是否需人工复核`：`是`、`否`
- `风险类型`：`废标`、`资格`、`报价`、`合同`、`时间`、`格式`、`暗标`、`冲突`、`缺失`、`其他`

## 完成前质量检查

在说明提取完成前，必须确认：

- [ ] 已深读前三章。
- [ ] 后续合同、技术、清单/报价、投标格式、附件、答疑、补遗已检查，或明确标记为未提供。
- [ ] 每条信息都有原文摘录和来源位置。
- [ ] 原文和业务解读分列。
- [ ] 商务标、技术标、资信标可独立查看。
- [ ] 综合通用事项没有被强行归入三类标书。
- [ ] 风险与复核清单包含冲突、缺附件、废标风险、人工复核事项。
- [ ] 已重点搜索高风险触发词。

## 常见错误

| 错误 | 修正 |
|---|---|
| 只做招标文件摘要 | 输出带原文摘录和来源位置的证据行 |
| 只读招标公告/投标人须知/评标办法 | 继续扫描合同、技术、清单、格式、附件、答疑、补遗 |
| 把原文和解读混在一起 | `原文摘录` 与 `业务解读` 分列 |
| 强行把所有事项归入商务/技术/资信 | 跨类别事项放入 `综合通用` |
| 漏掉投标格式下方附注 | 表格下方说明和附件注释按高优先级提取 |
| 不确定仍标记完成 | 降低可信度并设置 `是否需人工复核=是` |
