# 场景04：LOG增长分析

## 触发条件

用户询问 `Log增长计数`、`LOG增长计数` 或 LOG 是否有增长、变化。

典型问题：

- “高分07B01星20250806全天，Log增长计数是否有增长，增长的都是什么？”
- “高分07C01星20250806全天，LOG增长计数是否有变化？”

## 参数提取规则

- `satellites`：标准化后的卫星名称数组。
- `start_time`、`end_time`：左闭右开时间范围。

## 规则

- 固定分析参数为 `卫星LOG增长计数`。
- 不支持用户替换为其他参数。

## 强制脚本

必须调用 `scripts/log_growth.py`。

## JSON 参数格式

```json
{
  "satellites": ["高分07B01星"],
  "start_time": "2025-08-06 00:00:00",
  "end_time": "2025-08-07 00:00:00"
}
```

## 调用示例

```bash
python scripts/log_growth.py --json '{"satellites":["高分07B01星"],"start_time":"2025-08-06 00:00:00","end_time":"2025-08-07 00:00:00"}'
```

## 返回数据样例

```json
{
  "status": "success",
  "data": [
    {
      "卫星名称": "高分07B01星",
      "遥测参数名称": "卫星LOG增长计数",
      "遥测参数代码": "LOG_COUNT",
      "系统接收时间": "2025-08-06 10:00:00.000",
      "工程值": "3",
      "LOG标记详情": "标记1,标记2"
    }
  ]
}
```

## 展示规则

有增长数据时，先输出统计表：

| 卫星名称 | 检查对象 | 增长记录数 |
|---|---|---|

- `检查对象` 固定为 `卫星LOG增长计数`。
- 统计维度为 `卫星名称 + 检查对象`。
- 多卫星查询时，统计表必须覆盖全部请求卫星。
- 无增长记录的卫星显示 `0`。

然后输出增长明细表，字段使用脚本返回字段，第一列必须为“卫星名称”。

## 注意事项

- 本场景不需要 `metrics` 或 `condition`。
- LOG 增长的具体判断逻辑由脚本实现。
- 不输出总结、趋势分析、建议或异常原因推断
