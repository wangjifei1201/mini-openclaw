# 场景05：飞轮转速跳变

## 触发条件

用户询问飞轮转速是否有跳变或异常突变。

典型问题：

- “高分07B01星20250820000000-20250820100000，飞轮1转速、飞轮2转速、飞轮3转速、飞轮4转速是否有跳变？”
- “高分07C01星20250820全天，飞轮1转速和飞轮2转速是否有跳变？”

## 参数提取规则

- `satellites`：标准化后的卫星名称数组。
- `start_time`、`end_time`：左闭右开时间范围。
- `metrics`：飞轮标准参数名字符串数组。

## 同义词表

| 用户说法 | 标准参数名 |
|---|---|
| 飞轮1转速、飞轮转速1、飞轮1、1号飞轮转速 | 飞轮1转速 |
| 飞轮2转速、飞轮转速2、飞轮2、2号飞轮转速 | 飞轮2转速 |
| 飞轮3转速、飞轮转速3、飞轮3、3号飞轮转速 | 飞轮3转速 |
| 飞轮4转速、飞轮转速4、飞轮4、4号飞轮转速 | 飞轮4转速 |

用户同时提到多个飞轮时，展开为对应标准参数名列表。不得直接使用非标准名称。

## 强制脚本

必须调用 `scripts/flywheel_jump.py`。

## JSON 参数格式

```json
{
  "satellites": ["高分07B01星"],
  "start_time": "2025-08-20 00:00:00",
  "end_time": "2025-08-20 10:00:00",
  "metrics": ["飞轮1转速", "飞轮2转速", "飞轮3转速", "飞轮4转速"]
}
```

## 调用示例

```bash
python scripts/flywheel_jump.py --json '{"satellites":["高分07B01星"],"start_time":"2025-08-20 00:00:00","end_time":"2025-08-20 10:00:00","metrics":["飞轮1转速","飞轮2转速","飞轮3转速","飞轮4转速"]}'
```

## 分析方法

### 默认参数化配置表

```
window_size  稳定段连续秒数: 5
stability_tolerance 稳定段内波动最大值: 1
jump_threshold_ratio 跳变阈值比例: 10%
align_by_second 是否按秒聚合: 是
```

- 跳变阈值：默认 **基准值的 ±10%**（默认，可配置）
- 稳定段条件：**连续 N 秒**（默认 5 秒），**参数波动 ≤ M**（默认 1 或 1%）

### 三种输出状态定义

| 状态码                 | 状态名称            | 触发条件                             |
| ---------------------- | ------------------- | ------------------------------------ |
| `STABLE_NOT_FOUND`     | 未找到稳定段        | 无法找到符合条件的稳定段             |
| `STABLE_FOUND_NO_JUMP` | 稳定段存在 + 无跳变 | 找到稳定段，且后续所有点均未超过阈值 |
| `STABLE_FOUND_JUMP`    | 稳定段存在 + 有跳变 | 找到稳定段，且后续存在超过阈值的点   |

### 状态选择逻辑

```
11. 尝试寻找稳定段：
2   for 每个滑动窗口（长度 window_size）：
3        if 窗口内所有参数的 max - min <= stability_tolerance：
4            稳定段 = 该窗口
5            break
6
72. if 未找到稳定段：
8       状态 = STABLE_NOT_FOUND
9
103. else：
11       计算基准 = 稳定段内各参数的均值
12       for 稳定段之后的每个数据点：
13           if |当前值 - 基准| > 基准 * jump_threshold_ratio：
14                记录跳变
15
16       if 跳变列表为空：
17           状态 = STABLE_FOUND_NO_JUMP
18       else：
19           状态 = STABLE_FOUND_JUMP
```

## 注意事项

- `metrics` 是字符串数组，不是对象数组。
- 不得添加 `condition` 或 `extra_conditions`。
- 不输出总结、趋势分析、建议或异常原因推断
