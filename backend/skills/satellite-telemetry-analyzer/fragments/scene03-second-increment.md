# 场景03：秒递增检查

## 触发条件

用户询问某秒类参数是否每秒增加 1 或每秒递增。

典型问题：

- “高分07B01星20250730全天，卫星时间秒是否每秒增加1？”
- “高分07B01星、高分07C01星、高分07D01星20250730全天，PPS计数是否每秒增加1？”

## 参数提取规则

- `satellites`：标准化后的卫星名称数组。
- `start_time`、`end_time`：左闭右开时间范围。
- `param_name` 或 `param_code`：秒类参数名称或代码。

| PPS计数、PPS、秒脉冲计数 | PPS计数 |

若用户未明确指定秒类参数，默认使用 `卫星时间秒`。

## 强制脚本

必须调用 `scripts/second_check.py`。

## 参数构造

- **satellites**: 标准化后的卫星名称数组
- **start_time**, **end_time**: 左闭右开
- **param_name** 或 **param_code**: 映射后的标准参数名
- **不要添加 condition 或 extra_conditions**

## JSON 参数示例

```json
{
  "satellites": ["高分07B01星"],
  "start_time": "2025-08-19 00:00:00",
  "end_time": "2025-08-20 00:00:00",
  "param_name": "映射后的标准参数名"
}
```

## 调用示例

```bash
python scripts/second_check.py --json '{"satellites":["高分07B01星"],"start_time":"2025-08-19 00:00:00","end_time":"2025-08-20 00:00:00","param_name":"映射后的标准参数名"}'
```

## 返回数据样例

```json
{
  "status": "success",
  "data": [
    {
      "卫星名称": "高分07B01星",
      "遥测参数名称": "xx",
      "遥测参数代码": "PPS_COUNT",
      "系统接收时间": "2025-08-19 00:00:03.000",
      "工程值": "5"
    }
  ]
}
```

## 展示规则

有无异常数据时，都先输出统计表：

| 卫星名称 | 检查对象 | 总数量 | 异常数量 |
|---|---|---|---|

- `检查对象` 使用 `param_name`；使用代码查询时使用 `param_code`。
- 统计维度为 `卫星名称 + 检查对象`。
- 当用户一次查询多个卫星时，统计表必须展示所有请求卫星。
- 有递增异常的卫星显示异常数量。
- 没有递增异常的卫星显示 `0`。
- 异常数量为 `0` 的卫星不进入明细表。

然后输出异常明细表，字段使用脚本返回字段，第一列必须为“卫星名称”。

## 注意事项

- 不添加 `condition` 或 `extra_conditions`。
- 该场景只检查递增异常点。
- 不输出总结、趋势分析、建议或异常原因推断
