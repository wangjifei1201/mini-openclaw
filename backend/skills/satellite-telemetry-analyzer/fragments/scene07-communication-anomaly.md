# 场景07：通信异常检测

## 触发条件

用户询问某设备通电时，通信状态是否有异常，并且异常计数是否增加。

典型问题：

- “高分07D01星20250801070000-20250801080000，主份双频导航通断通电的情况下，导航通信状态是否有通信无效，并且主份导航通信异常计数是否增加？”

## 参数提取规则

- `satellites`：标准化后的卫星名称数组。
- `start_time`、`end_time`：左闭右开时间范围。
- `power_param`：通断参数名。
- `status_param`：通信状态参数名。
- `count_param`：通信异常计数参数名。
- `power_on_value`：默认 `通电`。
- `status_abnormal_value`：默认 `通信无效`。

## 强制脚本

必须调用 `scripts/comm_anomaly.py`。

## JSON 参数格式

```json
{
  "satellites": ["高分07D01星"],
  "start_time": "2025-08-01 07:00:00",
  "end_time": "2025-08-01 08:00:00",
  "power_param": "主份双频导航通断",
  "status_param": "导航通信状态",
  "count_param": "主份导航通信异常计数",
  "power_on_value": "通电",
  "status_abnormal_value": "通信无效"
}
```

## 调用示例

```bash
python scripts/comm_anomaly.py --json '{"satellites":["高分07D01星"],"start_time":"2025-08-01 07:00:00","end_time":"2025-08-01 08:00:00","power_param":"主份双频导航通断","status_param":"导航通信状态","count_param":"主份导航通信异常计数","power_on_value":"通电","status_abnormal_value":"通信无效"}'
```

```json
{
  "status": "success",
  "data": [
    {
      "卫星名称": "高分07D01星",
      "遥测参数名称": "主份导航通信异常计数",
      "遥测参数代码": "NAV_COMM_ERR_COUNT",
      "系统接收时间": "2025-08-01 07:30:00.000",
      "工程值": "2"

```

## 展示规则

有通信异常数据时，先输出统计表：

| 卫星名称 | 通断参数 | 通信状态参数 | 异常计数参数 | 异常数量 |
|---|---|---|---|---|

- `通断参数` 使用 `power_param`。
- `通信状态参数` 使用 `status_param`。
- `异常计数参数` 使用 `count_param`。
- 统计维度为 `卫星名称 + 通断参数 + 通信状态参数 + 异常计数参数`。
- 多卫星查询时，统计表必须覆盖全部请求卫星。
- 无通信异常的卫星显示 `0`。

然后输出异常明细表，字段使用脚本返回字段，第一列必须为“卫星名称”。

## 注意事项

- 本场景优先级高于普通通电条件范围判断。
- 默认通电值为 `通电`。
- 默认异常状态值为 `通信无效`。
- 不输出总结、趋势分析、建议或异常原因推断
