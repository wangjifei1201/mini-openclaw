# 参数发现步骤

## 目的

获取数据库中所有卫星、所有时间的遥测参数名称和代码，用于：

1. 确认用户提到的参数名称或代码是否存在。
2. 为后续场景脚本提供准确的参数名和代码映射。

此步骤不查询具体遥测数值，不执行卫星、时间或阈值筛选。

## 强制脚本

必须调用 `scripts/list_params.py`，且调用时传入空 JSON。

```bash
python scripts/list_params.py --json '{}'
```

## 参数匹配规则

- 用户提供参数代码时，优先按代码精确匹配。
- 用户提供参数名称时，优先按名称精确匹配。
- 精确匹配失败时，可使用包含关系查找候选项。
- 候选项最多返回 10 个。
- 未匹配到参数时，不得调用场景脚本。

## 输出示例

```json
{
  "data": [
    {"starname": "高分07B01星", "name": "蓄电池电压", "tmcode": "PD-C085"},
    {"starname": "高分07B01星", "name": "卫星时间秒", "tmcode": "SAT_SEC"}
  ]
}
```
