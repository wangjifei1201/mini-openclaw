# 场景01：单参数阈值判断

## 触发条件

用户指定一个参数名称或代码，并给出阈值条件：

- 低于、小于、`<`
- 高于、大于、`>`
- 等于、`=`
- 在 X-Y、X~Y、X到Y、X至Y 之间
- 满足 Y±Z

典型问题：

- “高分07B01星20250718全天，蓄电池电压是否有低于28V？”
- “高分07C01星20250730全天，飞轮1转速是否大于5000？”
- “高分07D01星20250819全天，WD-C001温度是否超过20.5？”

## 参数提取规则

- `satellites`：标准化后的卫星名称数组。
- `start_time`、`end_time`：左闭右开时间范围。
- `metrics`：数组，元素为 `{"type":"name","value":"参数名"}` 或 `{"type":"code","value":"参数代码"}`。
- `condition`：单值条件或区间条件。
- `extra_conditions`：无附加条件时使用空数组 `[]`。

## 强制脚本

必须调用 `scripts/query_range.py`。

## JSON 参数格式

```json
{
  "satellites": ["高分07B01星"],
  "start_time": "2025-07-18 00:00:00",
  "end_time": "2025-07-19 00:00:00",
  "metrics": [{"type": "name", "value": "蓄电池电压"}],
  "condition": {"operator": "<", "value": 28},
  "extra_conditions": []
}
```

## 调用示例

```bash
python scripts/query_range.py --json '{"satellites":["高分07B01星"],"start_time":"2025-07-18 00:00:00","end_time":"2025-07-19 00:00:00","metrics":[{"type":"name","value":"蓄电池电压"}],"condition":{"operator":"<","value":28},"extra_conditions":[]}'
```

## 返回数据样例

```json
{
  "status": "success",
  "data": [
    {
      "卫星名称": "高分07B01星",
      "遥测参数名称": "蓄电池电压",
      "遥测参数代码": "PD-C085",
      "系统接收时间": "2025-07-18 10:36:57.147",
      "工程值": "15.52271099"
    }
  ]
}
```

## 展示规则

有异常数据时，先输出统计表：

| 卫星名称 | 检查对象 | 异常数量 |
|---|---|---|

- `检查对象` 使用遥测参数名称；没有名称时使用遥测参数代码。
- 统计维度为 `卫星名称 + 检查对象`。
- 多卫星或多参数查询时，统计表必须覆盖用户请求的全部卫星和参数组合。
- 无异常的组合显示 `0`。

然后输出异常明细表，字段使用脚本返回字段，第一列必须为“卫星名称”。

## 注意事项

- 只处理通用单参数或多参数阈值判断。
- 若问题符合更高优先级场景，不使用本场景。
- 不输出总结、趋势分析、建议或异常原因推断
